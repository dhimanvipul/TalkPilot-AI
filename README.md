# TalkPilot AI — AI Outbound Calling Platform

> **"Your AI-powered calling assistant."**

TalkPilot AI is an enterprise-grade outbound conversational AI calling platform built with the MERN stack (MongoDB, Express, React, Node.js), Socket.IO, Tailwind CSS, Recharts, and Lucide Icons.

It is designed to make real outbound PSTN calls to mobile numbers via Twilio, while providing a zero-cost **Mock Calling Mode** (`CALLING_MODE=mock`) for local testing and demonstration.

---

## 🚀 Key Features

- **Full MERN Stack & Real-Time Sync**: Node.js/Express backend, MongoDB database (with automatic `mongodb-memory-server` fallback), React frontend built with `react-scripts` (NO Vite), and Socket.IO for live call event streaming.
- **Strict Real-Mode Verification**: When `CALLING_MODE=real`, calls are dispatched to Twilio via REST API. Statuses (`Initiating`, `Ringing`, `In Progress`, `Completed`, `Failed`, `No Answer`, `Busy`, `Cancelled`) are driven **ONLY by actual Twilio Webhook CallStatus callbacks**. Never faked!
- **AI Voice Agent Builder**: Define custom AI agents with system instructions, greeting messages, personalities, language models, voice parameters, and call objectives.
- **Contact Management & CSV Import/Export**: CRUD operations, search, filters, pagination, batch CSV file import, CSV export.
- **Do-Not-Call (DNC) & Opt-Out Protection**: Built-in consent verification and automatic DNC guard. Prevents automated calls to opted-out contacts.
- **Campaign Queue Engine**: Schedule campaigns, configure concurrency limits, dispatch rate intervals, retry limits, and track real-time queue dispatches.
- **Live Call Screen**: Real-time call monitor with animated audio waveforms, live call timers, multi-turn streaming transcripts via Socket.IO, and live mute/hangup controls.
- **Technical Debugging Panel**: Expandable technical section in Call Details showing Provider, Provider Call ID (CallSid), Last Webhook Status, Webhook Timestamp, and safe error messages.

## ⚙️ Calling Modes & Setup

### 1. Mock Calling Mode (`CALLING_MODE=mock`)
Ideal for local testing, demoing, and UI development without spending money.
- Simulates realistic multi-turn conversations, dialing, ringing, audio stream ticks, live Socket.IO transcripts, and AI call summaries.
- Set in `server/.env`:
  ```env
  CALLING_MODE=mock
  ```

---

### 2. Real Telephony Mode (`CALLING_MODE=real`)

#### Prerequisites for Real Calling:
1. **Twilio Account**: Active Account SID and Auth Token from [Twilio Console](https://console.twilio.com/).
2. **Twilio Phone Number**: A verified/purchased Twilio phone number capable of making outbound calls.
3. **Public HTTPS Webhook URL**: Twilio webhooks cannot reach `http://localhost:5000`. You must expose your local backend using an HTTPS tunnel such as **Cloudflare Tunnel** or **ngrok**:
   ```bash
   # Using ngrok
   ngrok http 5000
   ```
   Or using Cloudflare Tunnel (`cloudflared`):
   ```bash
   cloudflared tunnel --url http://localhost:5000
   ```

#### Environment Configuration (`server/.env`):
```env
CALLING_MODE=real

# Twilio Credentials
TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_AUTH_TOKEN=your_twilio_auth_token_here
TWILIO_PHONE_NUMBER=+18005550199

# Public HTTPS Webhook URL generated by ngrok or cloudflared
PUBLIC_WEBHOOK_URL=https://your-tunnel-name.ngrok-free.app
```

#### Real Call Dispatch & TwiML Flow:
```text
User Clicks "Start Call"
         │
         ▼
Validate Credentials & DNC Status
         │
         ▼
Twilio REST API (calls.create)
         │
         ▼
Provider returns CallSid (e.g. CA12345...)
Status set to "Initiating" (Stored in DB)
         │
         ▼
Customer's Phone Rings ("Ringing") ──(Webhook Status Callback)──► Database & Socket.IO
         │
         ▼
Customer Answers ("In Progress")   ──(Webhook Voice Callback)──► TwiML Voice & Speech Recognition
         │
         ▼
AI Conversation Engine ──(TwiML <Say> / <Gather>)──► Dynamic Customer Conversation
         │
         ▼
Call Ends ("Completed")           ──(Webhook Status Callback)──► Summary & Outcome Recorded
```

## 🛠️ Quick Start & Installation

### 1. Installation
Run from root directory:
```bash
npm run install-all
```

### 2. Seed Demo Data
Populate MongoDB with demo agents, contacts, and sample history:
```bash
npm run seed
```
- **Demo User:** `demo@talkpilot.ai`
- **Password:** `password123`

### 3. Run Development Server
```bash
npm run dev
```
- **Frontend Client:** `http://localhost:3000`
- **Backend API:** `http://localhost:5000`

## 📑 Required Environment Variables Matrix

| Variable | Description | Required in Mock Mode | Required in Real Mode |
|---|---|:---:|:---:|
| `CALLING_MODE` | `mock` or `real` | Yes | Yes |
| `TWILIO_ACCOUNT_SID` | Twilio Account SID (`AC...`) | No | **Yes** |
| `TWILIO_AUTH_TOKEN` | Twilio Auth Token | No | **Yes** |
| `TWILIO_PHONE_NUMBER` | Approved Twilio Outbound Number | No | **Yes** |
| `PUBLIC_WEBHOOK_URL` | Public HTTPS Webhook URL (ngrok/Cloudflare) | No | **Yes** |
| `AI_API_KEY` | OpenAI / AI Engine API Key | No | Optional |
| `JWT_SECRET` | Secret key for JWT auth tokens | Yes | Yes |

## 🔒 Security & Compliance
- **Opt-Out Protection**: Contacts marked as `optOutStatus: true` or `DO NOT CALL` are automatically blocked by the calling engine.
- **In-Call Opt-Out**: If a customer says *"stop calling"* or *"opt out"* during an AI call, TalkPilot AI automatically records the opt-out status and hangs up.
